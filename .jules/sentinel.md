## 2024-04-16 - Timing Attack Vulnerability in API Key Verification
**Vulnerability:** The API key verification in the FastAPI middleware used a standard string equality comparison (`token != _API_KEY`). This exposes the application to timing attacks where an attacker could theoretically guess the API key by measuring the response time of the verification process, since standard string comparison returns early on the first mismatched character.
**Learning:** Standard string comparison operators in Python (`==`, `!=`) are not designed for cryptographic or security-sensitive comparisons. This vulnerability existed because a basic equality check was used for token validation without considering side-channel attacks.
**Prevention:** Always use `secrets.compare_digest()` for comparing security-sensitive strings like passwords, API keys, and tokens. This function guarantees constant-time comparison, meaning the execution time is independent of the inputs' contents, effectively preventing timing attacks.
