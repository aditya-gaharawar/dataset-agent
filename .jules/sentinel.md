## 2024-05-18 - [CRITICAL] Fix API Key Timing Attack
**Vulnerability:** The FastAPI backend API key verification used a standard equality check (`token != _API_KEY`), which is vulnerable to timing attacks. An overly permissive CORS configuration (`allow_origins=["*"]` with `allow_credentials=True`) was also identified but fixing it would have introduced a breaking change.
**Learning:** Default equality checks (`!=`, `==`) short-circuit, leaking information about the matching prefix of a secret through response times. When fixing this with `secrets.compare_digest`, it's critical to ensure both inputs are strings to avoid crashing the server with a `TypeError`. Modifying CORS configurations to fix security issues often risks breaking legitimate cross-origin requests, so they require careful planning and coordination with frontend teams.
**Prevention:** Use constant-time comparison functions like `secrets.compare_digest` for verifying tokens or passwords to prevent timing attacks, always validating input types first. Coordinate CORS changes to avoid breaking changes.
